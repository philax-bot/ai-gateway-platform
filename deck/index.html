四条工程承诺

01

权限和钱分开记

模型权益与有效额度必须同时成立，加钱不会自动放开新模型。

02

默认不存正文

只留谁、何时、模型、Token、费用和结果等元数据，靠请求编号追溯。

03

只信平台自己的计价与快照

04

失败要看得见

中断、超时、用量缺失进入待核对，避免把未算清的账记成 0 元。

工程原则来自商务介绍 · 默认不保存正文，同样适用于安全事件

客户最常问的五个问题

Q　这跟直接用厂商 API 有什么区别？

A　平台管理公司里谁能用、用多少、从哪里扣钱，以及问题由谁处理；后面仍接各家模型厂商。

Q　会不会和某家厂商绑死？

A　模型、服务和协议都是配置项，可切换模型，也可接自建或私有化模型。

Q　运营能看我的对话内容吗？

A　默认不能，也不保存正文。运营看到模型、Token、费用、结果等调用元数据。

Q　员工额度用超了会怎样？

A　调用前拒绝并提示额度不足，不静默透支，也不自动从其他用途补扣。

Q　能按部门或职级自动开通吗？

A　按组织、人员类别、业务标签等条件配置。启用后默认影响新增或属性变化的人，存量需显式预览并应用。

自动开通条件为 AND 关系 · 组织范围一次性发放与长期自动开通政策分别配置
