# 联调与交付输入（E/F/G）

日期：2026-10-23。本文件只列出真实执行所需的最小输入和结果记录位置；没有目标和授权时不会发出外部请求。对应计划见 [实施与交接方案](IMPLEMENTATION-PLAN-2026-10-23.md) 第 7、8 节。

## 1. 使用方式

1. 复制下方对应表格，填入实际值。凭据只填“受控引用名称”（例如 `UPSTREAM_CUSTOMER_A`），不填写密钥明文。
2. 由环境负责人书面确认：允许发出的请求范围、测试预算、可中断窗口、证据保存位置。
3. 在隔离环境执行；真实模型与内网执行不得使用共享演示库或用户的审查工作区。
4. 结果写入本文件第 4 节或单独的验证记录，附机器配置、模型、并发、持续时间、样本数、错误率、TTFT/延迟和结算状态。未实际测量时不承诺固定 QPS。
