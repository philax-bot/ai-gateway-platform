## 边界

模型是本仓库 HTTP 替身，不是厂商模型或 Higress。schema 备份和恢复确实通过 PostgreSQL 原生工具执行，不是 JSON 导出导入。整机断电、磁盘损坏、异地恢复、正式凭据/TLS 与多主机日记管理仍未验收。原人工审查服务和业务数据保留。操作与恢复失败处理见 [备份与恢复](BACKUP-RESTORE.md)。
