# 网关运营能力第二轮方案

日期 2026-11-12。范围由本轮对话确定，包含路由解释、容量与 SLA 告警、供应商凭据运维、模型接入验收、多模态工作台与细粒度权限。

## 实施顺序

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| A | 权限基础，路由解释与试算，容量与 SLA 告警 | 接口与页面按职责授权。每次选路保留当时的候选、排序依据和跳过原因。试算读取实时快照。容量、延迟、积压指标可配置告警，告警可认领、静默、恢复并投递 Webhook |
| B | 供应商凭据运维，模型接入验收 | 上游凭据加密保存、版本化轮换、状态检查和使用统计。验收按服务配置版本记录实际协议与计量结果，并支持单次费用预估上限 |
| C | 多模态工作台与任务中心 | 员工按既有用途权限在线使用六类模型，查看任务与结果。视频任务支持列表、进度、下载、供应商支持的取消操作及完成回调 |
| D | 联合验收与本地交付 | 内存与 PostgreSQL 一致，覆盖角色越权、重复投递、轮换在途、任务恢复、实际选路与试算。完成五种界面、1440/390 布局、键盘操作和必要回归 |

权限基础贯穿三个功能阶段。每阶段沿用当前模型、用途、预占、结算和审计流程，新增能力从页面的正常入口进入。

## 权限方案

首版采用可组合的内置职责，角色在现有成员编辑入口分配。

| 职责 | 主要权限 |
| --- | --- |
| 平台管理员 `operator` | 平台配置、人员组织、职责分配及全部运营操作 |
| 模型运维 `model_operator` | 供应商、模型技术配置、池和路由管理，上游凭据运维，验收执行，运行监控与告警处理 |
| 财务运营 `finance_operator` | 费用与成本查询、计价配置、已有资金来源的额度管理、待核对费用处理 |
| 审计查看 `auditor` | 配置、调用、费用、运行记录与操作审计的只读查看 |
| 员工 `employee` | 现有个人、项目成员、应用负责人等责任范围内的自助操作 |

项目经理和应用负责人继续使用已有责任关系。角色权限在服务端判定，菜单、按钮、字段使用同一权限定义。技术配置与计价修改分别授权。平台管理员分配职责，最后一名有效管理员受到保护。

模型运维可查看处理故障需要的调用与计费结果。上游成本及计费倍率资料由财务运营、审计查看和平台管理员读取。平台库中的上游凭据以密文保存。受控直连在调用前解析绑定版本，Higress 发布时将认证值交给私有数据面配置。页面、操作审计和幂等回执不返回凭据明文。

## A 阶段

### 路由解释与试算

实际准入复用同一选路函数生成决策记录。记录逻辑模型、池、策略、配置版本、采样时间、候选服务、权重、优先级、容量占用、健康冷却、排序结果及跳过原因。结果跟随准入快照进入调用详情。

模型池页面提供试算入口。输入模型、预估输入和输出 Token 或媒体数量，可试用拟议的策略、权重与优先级。响应注明快照时间及服务级选路范围。真实调用仍按照调用者、用途、凭据、额度与当时容量重新准入。

### 容量与 SLA 告警

在已有错误率规则上增加 RPM、TPM、并发利用率，P95 总延迟与首字延迟，以及视频任务、待核对结算的积压数量和时长。规则支持池与服务范围、持续触发、恢复阈值、最小样本数、认领和限时静默。

通知首版提供站内通知与通用 JSON Webhook。通过持久化投递记录保存事件 ID、接收端、重试次数、结果和下一次重试时间。事件去重，失败退避重试，接收方可按事件 ID 幂等处理。Webhook 使用独立认证配置和签名，限制请求超时与重定向。

## B 阶段

### 供应商凭据

供应商页面管理命名凭据，记录供应商、名称、掩码、状态、当前版本、更新时间和关联服务。采用 AES-256-GCM 加密，控制面使用独立的主密钥配置。本地开发入口创建并复用受保护的开发密钥文件，生产环境通过部署秘密配置提供主密钥。

准入记录绑定凭据版本。在途调用与视频轮询使用绑定版本，新调用使用当前版本。禁用阻止新准入，历史调用和版本仍可追踪。凭据更换支持连接检查，鉴权失败记录版本与服务，不保存供应商密钥明文。

保留现有环境变量引用接入方式。托管凭据通过内部受控接口交给实际数据面，兼容当前 Higress 聊天与多模态受控适配器。

### 接入验收

区分目录连通性检查和实际调用验收。实际验收由有权限的用户显式发起，选择映射与测试项目，预览预计费用并设置单次费用预估上限。

测试项目覆盖普通响应、流式、工具调用及对应模态请求。记录响应格式、上游请求号、用量完整性、成本、错误分类、配置版本和完成时间。普通 Chat、流式、工具调用与五类同步模态分别保留验收记录，费用作为平台诊断成本记录。异步视频复用工作台与任务中心的持久化流程，按所选个人、项目或应用用途记账，并在调用记录中核对费用。

供应商用量和费用未知时显示待核对。费用上限约束可计算的请求规模和预占，实际供应商计费按返回用量记录。

## C 阶段

个人空间增加多模态工作台，复用当前用途、模型授权、额度报价和在线凭据。

| 类型 | 操作与结果 |
| --- | --- |
| 图片 | 输入提示词和数量，预览与下载图片 |
| ASR | 上传音频，查看识别文字和计量时长 |
| TTS | 输入文字、音色和格式，播放与下载音频 |
| Embedding | 输入单条或多条文本，查看向量维度、用量和 JSON |
| Rerank | 输入查询与候选文档，展示相关性排序 |
| 视频 | 提交生成，查询进度、失败原因、费用状态和结果，下载完成内容 |

任务中心按当前用户与用途过滤，运营按职责查看运行记录。文件下载使用流式转发。取消接口依据供应商配置与能力记录开放，取消后的费用按实际证据结算。完成回调使用持久化投递、签名和重试机制。

## 验收与范围控制

- 权限覆盖页面、读取接口、预览、写入、幂等重放与直接访问。使用真实低权限会话验证越权拒绝。
- 验收调用与通知投递使用隔离 PostgreSQL、本地模拟上游和本地 Webhook 接收端进行自动化验证。
- 真实供应商的联调结果按具体配置单独记录。已有参考仓库用于协议与运维设计核对。
- 日常入口为 `pnpm dev`，继续使用当前 PostgreSQL 工作区与既有外部开关。
- 客户 SSO、用户组织同步按客户接口需求另行定义。供应商账单自动对账保持暂缓。

## 实现裁决

- 角色在现有成员入口分配，首版为五类内置可组合职责。没有新增客户组织层级或 SSO 协议。
- 告警按分钟评估，实时容量页面仍按秒刷新。容量类规则使用即时快照，错误率和延迟使用完整滚动窗口。无上限分母显示未知，不能据此自动恢复。
- 异步视频实际验收在工作台发起一次正常用途调用，复用任务、费用与恢复流程，避免另设一个生成后难以恢复的诊断队列。同步验收使用独立诊断记录，不扣员工额度。
- 凭据轮换要求关联服务重新验证，新请求使用新版本。在途与历史视频结果访问保留原版本。供应商是否继续接受旧密钥取决于其撤销策略，平台不承诺被供应商撤销的旧值仍能调用。
- 完成回调由管理员在应用配置中选择已登记签名接收端。只投递任务、状态、请求编号和接口路径，应用访问视频结果仍使用自己的 Key。
- 运营可按职责看任务运行记录，普通任务结果仍按任务所有者和应用负责人隔离。跨用户运行可见性不自动授予结果下载权限。
- 通知队列保存在既有 PostgreSQL 工作区的运行状态中，使用事务认领、租约和事件去重。接收端按事件编号幂等处理，传输采用至少一次语义。

验收结果见 [2026-11-12 本地验收记录](../validation/gateway-operations-v2-2026-11-12.md)。
