04 / MODEL ACCESS

一个池，两种明确的授权方式

选择模型池后还要表达授权模式。模型池负责权限范围，服务状态决定当前能否使用。

范围选择器

默认池只为新建 / 审批预填，不迁移已有权益。
授权方式
选择授权模型

先切到“仅指定模型”，再模拟新增，观察范围是否扩大。这里展示的是编辑草稿。

不同角色看到不同字段

员工申请开通 / 创建项目

填写事项、场景和说明。无需选择模型池。

运营审批 / 直接创建

默认预填模型池，确认跟随或指定范围后批准。

个人追加额度

沿用已有权益，只补额度，不重新选池或扩大模型范围。

项目成员使用

继承项目模型范围；加入项目与获得额度是两步。

服务停用时保留授权、余额和历史，阻止对应模型的新调用。
05 / QUOTA & TRACE

让每一笔可用额度，都有来处

用途总余额与当前模型适用余额分开显示；不混加个人、项目和其他方案的资金。
