## 行为与范围

- Chat / Responses 的输出参数保持可选，支持未指定及 `null`；Messages 保留协议本身的必传要求。未指定且没有管理员输出限制时，不给上游添加输出参数；已有明确管理员限制继续执行。
- 请求的生成上限与初始预占分开。显式 80000 仍是生成上限，不把内部预计输出改写成生成限制。
- 模型定义新增可选 `estimatedOutputTokens`，默认 16384，可在“模型配置 → 模型目录 → 编辑”调整。仅用于费用和 TPM 预留，取模型配置/默认值、请求/策略限制、剩余上下文的较小值。不自动学习历史 P95。
- 报价和准入共用估算；持久化准入快照记录输入、预计输出和配置来源。逻辑幂等键与原请求指纹未更换，旧快照不重算。
- 完整权威 usage 超过初始预占时，使用冻结价格，从原批次原子补扣。余额不足继续待核对，不借用其他批次/用途；记账模式可补记负余额。未知用量继续保留预占。
- 在线使用默认留空输出参数，区分生成上限、预计输出与初始预占，并说明补差与待核对行为。数字字段复用 `Field`，没有新增页面样式。

这不是“模型在途消费绝不超出配额”的保证：估算允许低于实际消费，配额不足的已发生费用进入待核对。图片输入仍沿用此前的 Base64 剔除和每张 8192 tokens 预算；本轮没有实现按厂商图片尺寸规则精算。
